# 📚 ReadQuest

> **Learn English One Story at a Time.**

An interactive reading adventure where children can read fun stories, answer quizzes, learn new vocabulary, and become Reading Heroes.

---

## 🌟 Features

- 📖 Interactive reading stories
- 🧠 Reading comprehension quizzes
- 📚 Vocabulary section
- ⭐ Score and results page
- 🎮 Mission-based learning experience
- 📱 Responsive design (Desktop, Tablet, Mobile)
- 🚀 No installation required
- 💯 100% Frontend (No Database)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## 🎯 Learning Objectives

ReadQuest aims to help students:

- Improve English reading comprehension
- Learn new vocabulary words
- Practice critical thinking
- Build reading confidence
- Enjoy learning through interactive missions

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start your reading adventure!

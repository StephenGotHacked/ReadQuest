# 📚 ReadQuest

> **Learn English One Story at a Time.**

An interactive reading adventure where children can read fun stories, answer quizzes, learn new vocabulary, and become Reading Heroes.

---

## 🌟 Features

- 📖 Interactive reading stories
- 🧠 Reading comprehension quizzes
- 📚 Vocabulary section
- ⭐ Score and results page
- 🎮 Mission-based learning experience
- 📱 Responsive design (Desktop, Tablet, Mobile)
- 🚀 No installation required
- 💯 100% Frontend (No Database)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
